# Sistema de facturación multiempresa

Proyecto desarrollado desde cero por **Luis Antonio Serrano García en colaboracion con Deker Chavez Arce** durante mi residencia profesional en **Marpa IT**, para atender los requerimientos de facturación de la empresa.

**Estado:** en desarrollo y revisión. La integración con un PAC real continúa pendiente de validación de punta a punta.

## Tecnologías

- C# y .NET 10
- ASP.NET Core Web API
- Blazor WebAssembly y MudBlazor
- Entity Framework Core y SQL Server
- ASP.NET Core Identity y JWT
- Aplicación web progresiva (PWA)
- xUnit para pruebas automatizadas

## Funcionalidades

- Gestión de empresas emisoras, usuarios y permisos.
- Catálogos de clientes y productos.
- Administración de series, folios y bolsa de timbres.
- Captura de borradores y cálculo de impuestos.
- Generación de salidas PDF y XML.
- Panel de operación para cuentas, paquetes y compras.

## Mi participación

Desarrollo integral desde el inicio: backend, interfaz, persistencia e integración de funcionalidades conforme a los requerimientos de la empresa. El proyecto sigue en evolución durante la residencia profesional.

## Estructura de la solución de desarrollo

- **Facturacion.Client:** cliente Blazor WebAssembly.
- **Facturacion.Server:** API ASP.NET Core y servicios del servidor.
- **Facturacion.Shared:** contratos compartidos.
- **tests:** proyectos de pruebas.

La rama pública **main** contiene actualmente la presentación documental del proyecto. No incluye una distribución ejecutable del sistema.
